## 1. 业务目标与数据现状

**业务目标**：从采集数据中找**可能使用焊锡膏的公司**（SMT/PCBA 电子制造相关，
含自有产线制造商、电子代工厂、SMT 设备/辅料厂商等）。

**数据现状**（`zhilian` 库）：
- `positions` 49557 行 / `companies` 1726 家 / 采集关键词 48 个（SMT/PCBA/贴片/回流焊/AOI/SPI/锡膏…）
- `positions` 可过滤字段：`position_name`、`job_type`（智联岗位大类）、`company_name`、
  `job_desc`（已清洗纯文本，原始 HTML 在 `raw_json`）、`work_city`
- 公司行业在 `companies.industry_name`（positions 无行业字段，需 JOIN）

## 3. 关键洞察（清洗时不可按岗位一刀切）

### 3.1 销售岗位是混合的，不能全删
- ❌ 无关：养老行业销售、食品（千禾味业）、E-bike 销售、房地产销售
- ✅ **目标生态**：IC 芯片销售工程师（深圳玚弘）、电机驱动器销售工程师（拓邦股份）、
  大客户项目主管（汉旗电子科技）——电子元件/设备的销售正是焊锡膏上下游
- **处理**：销售岗要结合**公司行业**判断，公司是电子制造 → 该销售岗也算目标线索

### 3.2 人力资源/外包公司是干扰 + 线索并存
- 万宝盛华（Manpower）等猎头/劳务公司代招"SMT 工程师（ESS Technician）"、CAD、物流岗…
- 公司本身**不用焊锡膏**（黑名单行业），但**代招岗位的描述里可能有真实雇主**（目标线索）
- **处理**：人力资源公司整体排除出"目标公司"，但其代招岗位**不删**，作为线索单独标记

### 3.3 印刷/包装/纸箱厂是纯干扰
- 山东新兴华（纸箱包装）命中"生产机长/普工/仓管"——因通用词（生产/车间/生产线/批量生产）
  被关键词命中，与焊锡膏完全无关
- **处理**：行业黑名单（印刷/包装/造纸）+ 无核心制造词 → 排除

### 3.4 后勤岗（司机/保洁/保安）归属于目标公司与否决定价值
- 可属于目标公司（仪器仪表/半导体招保洁），也可属于无关公司（生物制药招保洁）
- **处理**：后勤岗本身不是目标信号，但**不删除**（公司判定用行业+岗位构成，不依赖单岗位）

### 3.5 核心结论：判断单元必须是"公司"，不是"岗位"
- 公司是否电子制造/SMT 相关，看它的**行业 + 岗位构成**，而不是单个岗位名
- 一个电子厂招保洁/会计，不影响它是焊锡膏目标客户

## 5. 清洗方法论

### 5.1 分层策略（公司维度为核心）
```
① 清洗 companies.industry_name 脏数据（重复拼接 → 去重取首值）
② 每公司提取岗位信号：核心制造词命中（position_name/job_desc）+ job_type 构成
③ 分层判定：
   TARGET  (目标)   = 行业白名单 OR 核心制造词命中（任一强信号）
   SUSPECT (可疑)   = 证据不足（中性行业 + 无核心词，或仅"印刷"类弱词）
   EXCLUDE (无关)   = 行业黑名单 AND 无核心制造词（如人力资源/纸箱厂/餐饮）
④ 代招线索：人力资源/外包公司岗位不删，描述里解析真实雇主 → 单独标记
⑤ 产出：目标公司清单（含证据链）+ 统计
```

### 5.2 方法选择：关键词集合为主 + 少量正则，非纯正则
| 方法 | 适用 | 原因 |
|---|---|---|
| **关键词集合**（set + 子串/分词匹配）| 中文词匹配（贴片/焊膏/锡膏）| 易维护、误杀可控、词边界不敏感 |
| **少量正则** | 精确模式（`SMT`、`PCB[AE]`、英文词边界 `\b`）| 英文缩写词边界（防"SMT"误匹配"SMTP"）|
| 行业白/黑名单集合 | companies.industry_name 精确匹配 | 分类清晰、可配置 |

> 正则不是主角：中文岗位匹配用正则容易漏边界（"SMT工程师" vs "SMT贴片"），
> 关键词子串匹配 + 少量词边界正则最稳。规则建议放 `config/*.json` 可配置。

### 5.3 误杀控制原则
- **宁滥勿缺**：目标是找潜在客户，漏掉真实目标公司损失 > 多留几个干扰公司
- **双层证据**：行业白名单 OR 核心词命中 → 才判 TARGET；单证据不足 → SUSPECT 待查
- **只标记不删**：判定结果用标记/清单表达，不直接 DELETE，可回溯、可重跑
- **代招线索保留**：人力资源公司虽非目标，但其岗位描述含真实雇主线索，单独处理不删

## 6. 待定决策点（后续数据分析时确定）

| 决策点 | 选项 | 倾向 |
|---|---|---|
| 处理动作 | 打标不删（脚本标记+清单） vs 直接删脏岗位 | 打标不删（可回溯）|
| 判定倾向 | 宁滥勿缺 vs 宁缺毋滥 | 宁滥勿缺 |
| 产出形式 | 目标公司清单 CSV vs CSV + DB 标记列 | 清单 CSV（带证据链）|
